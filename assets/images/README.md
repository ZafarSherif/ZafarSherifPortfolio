# Image Assets Guide

## Required Images

Place your images in this directory with the following names:

### Profile Image
- **File name:** `profile.jpg` or `profile.png`
- **Recommended size:** 800x800px (square)
- **Purpose:** Your professional headshot for the About section
- **Tips:** Use a high-quality photo with good lighting

### Project Images
- **File names:** `project1.jpg`, `project2.jpg`, `project3.jpg`
- **Recommended size:** 1200x800px (landscape, 3:2 ratio)
- **Purpose:** Screenshots or promotional images of your casino games
- **Tips:**
  - Use actual game screenshots
  - Show the most interesting/engaging parts of your games
  - Ensure images are high quality but optimized for web (compressed)

## Image Optimization Tips

1. **Compress images** before uploading using tools like:
   - TinyPNG (https://tinypng.com)
   - ImageOptim (Mac)
   - Squoosh (https://squoosh.app)

2. **Recommended formats:**
   - JPEG for photos
   - PNG for images with transparency
   - WebP for best compression (modern browsers)

3. **Target file sizes:**
   - Profile image: < 200KB
   - Project images: < 300KB each

## Temporary Placeholders

If you don't have images ready yet, you can use placeholder services:
- https://via.placeholder.com/800x800
- https://picsum.photos/800/800
- https://placehold.co/800x800

Example in HTML:
```html
<img src="https://via.placeholder.com/800x800" alt="Your Name">
```

## Additional Images (Optional)

You can add more project images by:
1. Adding more image files (project4.jpg, project5.jpg, etc.)
2. Duplicating the project card HTML structure in index.html
3. Updating the image src attributes accordingly
